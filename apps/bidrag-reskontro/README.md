# Bidrag-reskontro
Applikasjon for å hente ut hva skatt har krevd inn og eventuell gjeld.

## Beskrivelse
Bidrag-reskontro er en applikasjon for å hente ut informasjon fra skattetaten, via Elin, om innkrevd og/eller innbetalt gjeld.
